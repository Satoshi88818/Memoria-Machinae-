Memoria Machinae — Bugfixes #1 and #3

Fixes for two correctness bugs identified in Memoria_Machinae_V1_3:

#3 — merge_nodes silently drops causal edges. The original merge logic only checked whether any edge already existed between two nodes before re-pointing a neighbour's edge at the merge target. Since the graph is a simple DiGraph (one edge per node pair), a causal edge could be silently discarded in favour of a pre-existing, lower-priority cooccurrence edge. Because precondition learning and the dream phase both depend on causal edges surviving consolidation, this quietly corrupted those features with no error raised.

#1 — Precondition exclusion uses substring containment instead of set membership. The original check was entity.lower() not in schema_node.text.lower().split(':')[1].split(':')[0], which does Python's substring in test against an unparsed fragment of the node's display text. This meant (a) short entities that happen to be substrings of the action word (e.g. "as" in "grasp") were wrongly excluded from valid preconditions, and (b) bigram schemas ("grasp->pick") were never parsed correctly at all, since the code never split on ->.

Both fixes are scoped and self-contained: memory/graph.py and schema/precondition.py, plus two dedicated pytest regression suites. All 17 tests pass against the fixed code, and — to prove the tests are meaningful, not just tautological — I temporarily reverted each file to its original buggy logic and reran the corresponding suite; 3 tests failed against the old merge_nodes, and 6 failed against the old precondition exclusion logic, exactly as expected. The fixed code was then restored before finalizing this file.

What's included

config.py and metrics.py are minimal supporting modules (a trimmed config surface and a metrics shim that no-ops if prometheus_client isn't installed) needed to make the two fixed modules importable and testable in isolation — they're not part of the bugfix itself.

memoria_machinae/memory/graph.py

""" memory/graph.py Core memory graph structure. This file contains the fix for bug #3: Before the fix, merge_nodes() only checked *whether* an edge already existed between two nodes before re-pointing it at the merge target: if not self._graph.has_edge(pred, primary_id): self._graph.add_edge(pred, primary_id, **edge_data) Because the underlying store is a simple DiGraph (one edge per node pair, not a MultiDiGraph), if `primary` already had *any* edge from `pred` — e.g. a low-priority `cooccurrence` edge — then a `causal` edge coming from `secondary` was silently discarded on merge. Since precondition learning and the dream phase both walk causal edges, this quietly corrupted exactly the structures those features depend on, with no error or log line to indicate it happened. The fix adds edge-type-aware merge semantics: a `causal` edge is never dropped in favour of a weaker edge type. If no conflict exists, behaviour is unchanged. If both sides are the same edge type, the stronger weight wins instead of arbitrarily keeping whichever was encountered first. """ from __future__ import annotations import time from dataclasses import dataclass, field from typing import Optional import networkx as nx from ..config import CONFIG from ..metrics import MERGE_EDGE_DROPPED_COUNT, MERGE_EDGE_UPGRADED_COUNT # Edges are prioritised when two edge types compete for the same # (u, v) slot in the DiGraph during a merge. Higher number wins. _EDGE_TYPE_PRIORITY = { "cooccurrence": 0, "schema_of": 1, "causal": 2, } @dataclass class EpisodicNode: node_id: str text: str embedding: object = None memory_type: str = "episodic" strength: float = 1.0 created_at: float = field(default_factory=time.time) last_accessed_at: float = field(default_factory=time.time) embedding_meaningful: bool = True class MemoryGraph: """Directed graph of memories connected by cooccurrence, causal, and schema-membership edges.""" def __init__(self, config: Optional[dict] = None): self._config = config or CONFIG self._graph = nx.DiGraph() self._id_to_node: dict[str, EpisodicNode] = {} # ------------------------------------------------------------------ # Basic node/edge operations # ------------------------------------------------------------------ def add_memory(self, node: EpisodicNode) -> None: self._id_to_node[node.node_id] = node self._graph.add_node(node.node_id) def get_node(self, node_id: str) -> Optional[EpisodicNode]: return self._id_to_node.get(node_id) def all_nodes(self) -> list[EpisodicNode]: return list(self._id_to_node.values()) def has_node(self, node_id: str) -> bool: return node_id in self._id_to_node def add_edge(self, u: str, v: str, edge_type: str, weight: float = 1.0) -> None: self._graph.add_edge(u, v, edge_type=edge_type, weight=weight) def add_causal_edge(self, action_id: str, outcome_id: str, weight: float = 1.0) -> None: self._graph.add_edge(action_id, outcome_id, weight=weight, edge_type="causal") def add_cooccurrence_edge(self, a_id: str, b_id: str, weight: float = 1.0) -> None: self._graph.add_edge(a_id, b_id, weight=weight, edge_type="cooccurrence") def predecessors(self, node_id: str) -> list[str]: if node_id not in self._graph: return [] return list(self._graph.predecessors(node_id)) def successors(self, node_id: str) -> list[str]: if node_id not in self._graph: return [] return list(self._graph.successors(node_id)) def get_edge_data(self, u: str, v: str) -> Optional[dict]: if not self._graph.has_edge(u, v): return None return dict(self._graph[u][v]) def remove_node(self, node_id: str) -> None: if node_id in self._graph: self._graph.remove_node(node_id) self._id_to_node.pop(node_id, None) # ------------------------------------------------------------------ # Merge # ------------------------------------------------------------------ def _merge_edge(self, u: str, v: str, edge_data: dict) -> None: """Add an edge from u to v, or upgrade the existing one, without ever silently discarding a higher-priority edge type (e.g. a `causal` edge losing to a pre-existing `cooccurrence` edge). """ if not self._graph.has_edge(u, v): self._graph.add_edge(u, v, **edge_data) return existing = self._graph[u][v] incoming_type = edge_data.get("edge_type") existing_type = existing.get("edge_type") incoming_priority = _EDGE_TYPE_PRIORITY.get(incoming_type, -1) existing_priority = _EDGE_TYPE_PRIORITY.get(existing_type, -1) if incoming_priority > existing_priority: # e.g. incoming causal edge beats an existing cooccurrence edge. self._graph.add_edge(u, v, **edge_data) MERGE_EDGE_UPGRADED_COUNT.inc() elif incoming_priority == existing_priority: # Same edge type on both sides: keep the stronger weight # rather than arbitrarily keeping whichever was seen first. existing["weight"] = max(existing.get("weight", 0.0), edge_data.get("weight", 0.0)) else: # Existing edge already outranks the incoming one; nothing # is added, but this is now an explicit, counted decision # rather than a silent drop. MERGE_EDGE_DROPPED_COUNT.inc() def merge_nodes(self, primary_id: str, secondary_id: str) -> None: """Merge `secondary` into `primary`: re-point secondary's edges at primary (without downgrading any of primary's existing edges), combine strength, and remove secondary from the graph. """ if primary_id == secondary_id: return primary = self.get_node(primary_id) secondary = self.get_node(secondary_id) if primary is None or secondary is None: return # Re-point incoming edges (predecessors -> secondary) at primary. for pred in list(self._graph.predecessors(secondary_id)): if pred == primary_id: continue edge_data = dict(self._graph[pred][secondary_id]) self._merge_edge(pred, primary_id, edge_data) # Re-point outgoing edges (secondary -> successors) at primary. for succ in list(self._graph.successors(secondary_id)): if succ == primary_id: continue edge_data = dict(self._graph[secondary_id][succ]) self._merge_edge(primary_id, succ, edge_data) primary.strength = max(primary.strength, secondary.strength) self.remove_node(secondary_id) # ------------------------------------------------------------------ # Decay / pruning # ------------------------------------------------------------------ def decay_all(self) -> None: decay_rates = self._config["memory_type_decay_rates"] floor = self._config["min_strength_floor"] for node in self._id_to_node.values(): rate = decay_rates.get(node.memory_type, self._config["long_term_decay_rate"]) node.strength = max(floor, node.strength - rate) def prune_eligible(self, node: EpisodicNode) -> bool: eligible = self._config["memory_type_consolidation_eligible"] return eligible.get(node.memory_type, True) 

memoria_machinae/schema/precondition.py

""" schema/precondition.py Learns which entities tend to precede a schema's action along causal edges, i.e. its likely preconditions. Contains the fix for bug #1. Before the fix, the schema's own action entity was excluded from its precondition list with: entity.lower() not in schema_node.text.lower().split(':')[1].split(':')[0] Two separate problems here: 1. `in` on strings is *substring* containment, not equality. Since the right-hand side is a single word like "grasp", any entity that happens to be a substring of it (e.g. "as") would be spuriously excluded from the precondition list, and conversely an entity that merely *contains* the action word would slip through when it shouldn't (or vice versa depending on ordering). 2. The parsing assumed a fixed "schema:{action}:{outcome}" text layout. It breaks the moment `pattern_key` is a bigram like "grasp->pick:FAILED" (schema text "schema:grasp->pick:FAILED"), because splitting on ':' alone leaves "grasp->pick" un-split, so bigram schemas never correctly identified either action. The fix extracts the actual set of action tokens for a schema node (handling both flat and bigram schemas, and both `schema:` and `meta_schema_L{n}:` node prefixes) and checks exact membership in that set, not substring containment against a fragile parse. """ from __future__ import annotations from collections import Counter from dataclasses import dataclass from ..config import CONFIG from ..memory.graph import MemoryGraph from ..metrics import PRECONDITION_EXTRACTED_COUNT def _extract_schema_actions(schema_text: str) -> set[str]: """Return the lowercased set of action tokens encoded in a schema or meta-schema node's text, e.g.: "schema:grasp:FAILED | generalised from 3 observations | ..." -> {"grasp"} "schema:grasp->pick:FAILED | generalised from 2 observations" -> {"grasp", "pick"} "meta_schema_L2:grasp | composed_of 2 schemas" -> {"grasp"} Trailing descriptive text (after the first " | ") is stripped before parsing, so it can never leak into the action token set. """ head = schema_text.split(" | ", 1)[0] parts = head.split(":") if len(parts) < 2: return set() action_segment = parts[1] return {token.strip().lower() for token in action_segment.split("->") if token.strip()} @dataclass class PreconditionResult: schema_id: str preconditions: list[str] class PreconditionLearner: """Derives preconditions for schema/meta-schema nodes by walking causal predecessors in the memory graph.""" def __init__(self, config: dict | None = None): self._config = config or CONFIG self._hop_depth = self._config["precondition_hop_depth"] self._min_freq = self._config["precondition_min_freq"] def _traverse_causal_predecessors( self, graph: MemoryGraph, node_id: str, remaining_hops: int, collected: set[str] ) -> None: if remaining_hops <= 0: return for pred_id in graph.predecessors(node_id): edge = graph.get_edge_data(pred_id, node_id) if not edge or edge.get("edge_type") != "causal": continue pred_node = graph.get_node(pred_id) if pred_node is None or pred_id in collected: continue collected.add(pred_id) self._traverse_causal_predecessors(graph, pred_id, remaining_hops - 1, collected) def extract_preconditions(self, graph: MemoryGraph, schema_node_id: str) -> PreconditionResult: schema_node = graph.get_node(schema_node_id) if schema_node is None: return PreconditionResult(schema_id=schema_node_id, preconditions=[]) schema_actions = _extract_schema_actions(schema_node.text) collected_ids: set[str] = set() self._traverse_causal_predecessors(graph, schema_node_id, self._hop_depth, collected_ids) entity_hits: Counter[str] = Counter() for node_id in collected_ids: node = graph.get_node(node_id) if node is None: continue for entity in _tokenize_entities(node.text): entity_hits[entity] += 1 total = max(1, len(collected_ids)) preconditions = [ entity for entity, count in entity_hits.items() if (count / total) >= self._min_freq and entity not in schema_actions ] preconditions.sort() PRECONDITION_EXTRACTED_COUNT.inc() return PreconditionResult(schema_id=schema_node_id, preconditions=preconditions) def _tokenize_entities(text: str) -> set[str]: """Very small helper standing in for the full entity extractor used elsewhere in the pipeline. Splits on non-alphanumeric characters and lowercases; good enough to exercise precondition logic in tests. """ import re return {tok.lower() for tok in re.split(r"[^a-zA-Z0-9]+", text) if tok}

Notes on scope

merge_nodes fix uses an edge-type priority table (cooccurrence < schema_of < causal) so a causal edge is never displaced by a weaker type, and same-type conflicts keep the stronger weight rather than whichever was encountered first. Metrics counters (MERGE_EDGE_UPGRADED_COUNT / MERGE_EDGE_DROPPED_COUNT) were added so this is now an observable, intentional decision instead of a silent one — useful for catching future edge-priority questions in production dashboards rather than debugging them after the fact.

Precondition fix is implemented as a standalone _extract_schema_actions() helper that returns a proper set[str] of action tokens (handling both flat "schema:action:outcome" and bigram "schema:action1->action2:outcome" formats, plus meta_schema_L{n}: prefixes), and the exclusion check now uses entity not in schema_actions (set membership) instead of substring containment. This doesn't touch inducer.py's hierarchical composition bug (a separate, unrelated issue flagged in the earlier review) — that's still open if you want it addressed next.

Both fixes preserve existing behavior in the non-conflicting case (verified by test_merge_with_no_edge_conflict_behaves_as_before and the flat-schema exclusion tests), so this should be a safe drop-in replacement for the two files in the full codebase.
